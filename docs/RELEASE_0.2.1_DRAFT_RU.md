# TinyCraft v0.2.1 — черновик описания релиза

> Предварительное описание по текущим изменениям ветки. Перед публикацией нужно пройти ручной QA и собрать финальный Windows ZIP.

TinyCraft v0.2.1 — большой стабилизационный релиз мира, рендера и multiplayer. Основная цель версии — убрать критические гонки и дыры чанков, разделить обычный мир и Paradise, сделать сохранения надёжнее и приблизить dedicated server к поведению singleplayer.

## Главное

- Обычный мир и Paradise теперь хранятся отдельно как `world` и `world-paradize`.
- Старые Paradise-данные читаются и переносятся в новую структуру совместимым способом.
- Для измерений разделены загруженные чанки, игровые таймеры, мобы, выброшенные предметы и контейнеры.
- Сохранения метаданных, игроков и игровых данных записываются через безопасную атомарную замену файлов.
- Мобы и контейнеры сохраняются отдельно для обоих измерений.
- В новых чанках низкие участки берега заполняются водой до уровня моря, а `seagrass` и `kelp` размещаются внутри водяного слоя.

## Survival

- Survival-игрок больше не продолжает игру с `0 HP`: смертельный урон открывает экран смерти и обычный respawn.
- При непрерывном спринте hunger уменьшается с интервалом 20 секунд вместо слишком быстрого расхода.
- При hunger не ниже 18 здоровье естественно восстанавливается.
- Регенерация и полученный урон сначала расходуют скрытый двухминутный запас сытости, затем видимую полоску hunger.

## Multiplayer и dedicated server

- Player state, действия с контейнерами, выбрасывание предметов, команды и сохранение при отключении применяются в основном server tick, а не параллельно из socket-thread.
- Контейнеры и item drop обрабатываются в измерении конкретного игрока.
- Ломание блоков проверяется сервером по расстоянию, времени, выбранному слоту и реальному предмету в руке.
- Сервер рассчитывает урон и отбрасывание по авторитетному предмету игрока.
- Правила дропа объединены для singleplayer, LAN и dedicated server.
- Исправлены стадии и количество дропа пшеницы, моркови и картофеля, а также `kelp` и `seagrass`.
- В creative сервер больше не создаёт block-item после разрушения блока.
- Инвентарь не изменяется частично, если целая выдаваемая стопка не помещается.
- Добавлены и усилены команды `/tp`, `/kill`, `/summon`, `/setblock`, `/fill`, `/gamemode`, `/give`, `/clear` и их серверные проверки прав.
- Публичные команды остаются доступными без читов, а gameplay-команды требуют `allowCheats` или прав оператора.
- Настройка `allowCheats` сохраняется в метаданных мира и передаётся при открытии LAN.

## Рендер и чанки

- Старый GPU mesh остаётся видимым, пока новый mesh полностью не построен и не загружен.
- Добавлены ревизии mesh-сборок: устаревший фоновый результат больше не заменяет свежий чанк.
- Исправлена инвалидизация соседних и диагональных секций на границах чанков.
- Улучшены приоритеты, лимиты и очереди фоновой сборки и загрузки mesh.
- Добавлены объединённые opaque-регионы с безопасной заменой GPU-буферов.
- Координаты рендера считаются относительно камеры; расширена упаковка вершин регионов для дальних координат.
- Пути запуска и шейдеров больше не должны зависеть от случайной рабочей папки процесса.

## Интерфейс, чат и настройки

- Чат получил историю сообщений, прокрутку, затухание, историю введённых команд и подсказки с `Tab`/`Shift+Tab`.
- Добавлены подсказки синтаксиса и аргументов команд с учётом доступности читов.
- Добавлены режимы ограничения FPS: VSync, 30–240 FPS и Unlimited.
- Добавлен автоматический и ручной масштаб GUI.
- Главное меню использует панораму, а меню поверх запущенного мира — размытый фон.
- `F2` сохраняет PNG-скриншот в `screenshots/`, а `F6` автоматически снимает шесть сторон панорамы.
- Меню `F3` разделено на игровую и системную колонки, масштабируется вместе с GUI, не использует общую чёрную подложку и выравнивает правую колонку по краю экрана.
- `F3 + G` переключает границы чанков; `F3 + F4` использует авторитетную серверную смену режима там, где она доступна.
- Управление вводом и логика игрока вынесены из основного god-класса в `InputController` и `PlayerController`.

## Надёжность и тесты

- Добавлены проверки атомарных сохранений, сетевого кодека, server authority, разрешений команд и сохранения инвентаря.
- Добавлены тесты независимости измерений, миграции Paradise, mesh-ревизий и границ чанков.
- Добавлены тесты чата, настроек FPS/GUI и единых правил дропа.
- Текущий автоматический набор: 108 JUnit-тестов.

## Совместимость и важные замечания

- Сетевой протокол текущей ветки: `VERSION = 7`; старые клиент и сервер `v0.2.1` несовместимы с этой пересобранной версией.
- Лаунчер уже ожидает `tag v0.2.1` и asset `TinyCraft-v0.2.1-windows.zip`.
- Если старая `v0.2.1` уже установлена через лаунчер, нужно выбрать «Обновить клиент»: автоматического удалённого manifest/checksum пока нет.
- Координаты около `100 000 000` пока не поддерживаются полностью: внутренние ключи блоков безопасны примерно до ±33,5 млн.
- Перед публикацией обязательны ручные проверки OpenGL и localhost multiplayer с двумя клиентами, контейнерами, item drop, `save` и повторным входом.
- Полный сценарий перед публикацией находится в `docs/QA_CHECKLIST_RU.md`.
- GitHub Release должен использовать tag `v0.2.1` и asset `TinyCraft-v0.2.1-windows.zip`.
