# TinyCraft Roadmap

Этот файл - короткий ориентир, чтобы не путаться в развитии проекта. Текущая стабильная база называется `v0.2 Final`, но проект продолжается. Следующий крупный ориентир - `TinyCraft v0.3`.

## Главный порядок

1. Сделать игру живее: бой, мобы, еда/голод, кровати, щит, тотем, понятный HUD.
2. Довести multiplayer до удобного сценария через VPS: dedicated server, документация, синхронизация новых gameplay-систем.
3. Держать launcher отдельно в `TinyCraftLauncher/`, не смешивая его с игровым кодом.

## Версии и релизы

- Игровые релизы: `v0.3`, `v0.3.1`, `v0.4`.
- Серверная документация идет внутри игровых релизов.
- GitHub Releases называются понятно: `TinyCraft v0.3`, `TinyCraft v0.3.1`, `TinyCraft v0.4`.

## Этап 1: Gameplay v0.3

- Бой: cooldown удара, разные уроны оружия, knockback, блокирование щитом, простой крит/слабый удар.
- Мобы: разные поведения hostile/passive, агро-радиус, бегство мирных мобов, атака с cooldown, дроп после смерти.
- Еда и голод: еда восстанавливает hunger, hunger влияет на реген/урон, простая сытость без сложной Minecraft-модели.
- Кровати: сон ночью, пропуск ночи в singleplayer, spawn point игрока, multiplayer-сон только когда все живые игроки в кровати.
- Щит и тотем: щит снижает или блокирует входящий урон при удержании, тотем один раз спасает от смерти и расходуется.
- UI: читаемый inventory/containers HUD, индикаторы здоровья/голода/брони/щита, подсказки еды и предметов.

## Этап 2: Multiplayer v0.3

- Починить никнеймы над remote players: имя над игроком, отсечение по дистанции, без наложения на UI.
- Синхронизировать новые системы: hunger, shield state, totem activation, bed/sleep state, улучшенный mob damage/drop.
- Основной серверный путь: Ubuntu VPS, Java 8+/17+, открытый TCP `25566`.
- Обновить документацию: аренда VPS, установка Java, загрузка ZIP, запуск, firewall, подключение по IP.
- Relay/NAT traversal не делать в первой итерации; это отдельный большой этап после стабильного dedicated server.

## Release Hygiene

- Для каждого игрового релиза прикладывать только игровые ZIP/JAR.
- В README держать отдельные инструкции для игры, сервера и отдельной папки лаунчера.

## Проверки перед релизом

- `javac -encoding UTF-8 --release 8 -cp "lib/*" -d out *.java`
- `.\run-tests.bat`
- Singleplayer вручную: бой, смерть, тотем, щит, еда, голод, сон, spawn point.
- Multiplayer вручную: dedicated server, два клиента, никнеймы, атаки, мобы, containers, сон, reconnect.
- Release вручную: проверить ZIP, manifest, SHA и запуск через лаунчер на чистой папке `%LOCALAPPDATA%\TinyCraftLauncher`.
