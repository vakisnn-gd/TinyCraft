# Правила работы с TinyCraft

- Одна задача должна давать один небольшой, сфокусированный diff.
- Перед любыми изменениями нужно запускать baseline-проверку.
- После изменений нужно запускать все тесты.
- Нельзя объявлять успех без exit code 0.
- Нельзя менять формат сохранений или сетевой протокол без прямой команды пользователя.
- Нельзя делать unrelated cleanup.
- Нельзя удалять, отключать или ослаблять тесты.
